# ZG16B promoter methylation and interpersonal violence: analysis code

Analysis code for the article *Aberrant ZG16B Promoter DNA Methylation in Oral Tissue of
Individuals Exposed to Interpersonal Violence: an epigenome-wide analysis of graded exposure with directional replication*
(Hernández Hincapié, Pinzón Reyes and Llanez Anaya; manuscript under review).

The R scripts in this repository run from the publicly deposited data and print the values reported
in the article. The tables and figures of the article are written to `outputs/`, together with the
session information of the scripts that fit models or draw figures.

## Data

All data are publicly available from the Gene Expression Omnibus (GEO) and are not redistributed here.
The scripts expect them in a folder `data/` at the root of the repository:

```
data/
  GSE226085/
    GSE226085.txt                                    sample records of the series (see below)
    GSE226085_geo_igp_processed_matrix_v1.csv.gz     processed matrix deposited by the authors
  evaluation/
    GSE239520.txt                                    sample records of the series
    GSE239521.txt                                    sample records of the series
    GSE239520/  GSM..._<Sentrix ID>_<position>_{Grn,Red}.idat.gz   (85 samples)
    GSE239521/  GSM..._<Sentrix ID>_<position>_{Grn,Red}.idat.gz   (123 samples)
```

| Accession | Role | Tissue | Files |
|---|---|---|---|
| GSE226085 | discovery cohort (n = 116, 42 extended families) | buccal epithelium | processed matrix (supplementary file of the series) |
| GSE239521 | replication cohort (n = 123) | saliva | raw IDAT files (supplementary files of the samples) |
| GSE239520 | third cohort (n = 85) | buccal epithelium | raw IDAT files (supplementary files of the samples) |

The sample records (`GSE*.txt`) are the SOFT text returned by
`https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=<accession>&targ=gsm&form=text&view=brief`.
The paths `BU` and `CM` at the top of each script can be edited if the data are kept elsewhere.

## Run order

The scripts read intermediate objects written by earlier scripts, so they must be run in this order,
from the root of the repository (for example, `Rscript 01_TRONCO_descubrimiento_y_replicacion.R`):

```
01 -> 02 -> 01b -> 01c -> 01d -> 02b -> 02c -> 03 -> 04
```

The intermediate objects (`outputs/*.RDS`, `T1_*`, `T2_*`) are regenerated by the scripts and are not
deposited. Scripts 03 and 04 first reproduce published coefficients and stop if they differ.

## Scripts

| Script | Content | Deposited outputs |
|---|---|---|
| `01_TRONCO_descubrimiento_y_replicacion.R` | First pass of the discovery model in GSE226085 (violence score as a continuous variable), the directional prediction fixed at the eight ZG16B promoter probes, and its evaluation in GSE239521. The primary genome-wide model reported in the article, on the imputed matrix, is fitted in 01b | `sessionInfo_tronco.txt` |
| `02_cohorte_discordante_GSE239520.R` | Evaluation of the fixed prediction in the third cohort | `S1_*` |
| `01b_sensibilidad_DMR_familia_permutacion.R` | KNN imputation and primary genome-wide model, Δβ, within-family correlation model (`duplicateCorrelation`), DMRcate regions and DMP–DMR intersection, descriptives and group comparability, technical replicates | `T0`, `T3`–`T6`, `S2`, `S3` |
| `01c_figuras_y_tablas_del_manuscrito.R` | Figures and tables of the article from the saved objects | `HernandezFig1-4.tif`, `TABLA1-4_*.csv`, `F2_distribuciones.csv` |
| `01d_sensibilidad_sondas_tabaco_familia.R` | Sensitivity analyses: complete-data probes only, methylation-derived smoking score and AHRR cg05575921 as covariates, one participant per family | `S7_*`, `S8_*`, `S9_*` |
| `02b_almacenamiento_GSE239520.R` | Storage time before DNA extraction in the third cohort | `S4_*` |
| `02c_sensibilidad_almacenamiento_GSE239520.R` | Evaluation of the prediction after excluding the long-storage samples | `S5_*` |
| `03_exploratorio_edad.R` | Exploratory analysis of age at the eight promoter probes: sign concordance by age group and exposure-by-age interaction in the three cohorts | `E1_*` |
| `04_figura_S2_una_por_familia.R` | Supplementary Fig. S2: promoter coefficients with all participants and with one participant per family | `HernandezFigS2.tif`, `FigS2_una_por_familia.csv` |

Session information is written by 01, 01b, 01c, 01d, 03 and 04 (`outputs/sessionInfo_*.txt`).
Table 1 is written in 01c with the cohort descriptives entered as values: those of the discovery
cohort are printed by 01b, and those of the evaluation cohorts can be recomputed from the GEO sample
records. Each script starts
with a header that states its purpose, the paper section it supports, its inputs and its outputs.
Object and file names, and console messages, are in Spanish; comments are in English.

## Correspondence with the article

Output files keep the working names of the analysis. Main tables: Table 1 = `TABLA1_cohortes`,
Table 2 = `TABLA3_DMR`, Table 3 = selected columns of `TABLA4_locus_tres_cohortes`. Figures:
Fig. 1 = `HernandezFig1`, Fig. 2 = `HernandezFig3`, Fig. 3 = `HernandezFig4`, Supplementary Fig. S1 =
`HernandezFig2`, Supplementary Fig. S2 = `HernandezFigS2`. Supplementary tables: S1 = `TABLA2_DMP`;
S2 = `S2_inventario_sondas_ZG16B`; S3 = `S1_cohorte_discordante_GSE239520`; S4 =
`S7_sondas_completas_locus`; S5 = `S8_tabaco_locus`; S6 = `S3_sensibilidad_replicas_tecnicas`;
S7 = `S9_una_por_familia_locus`; S8 = `S4_almacenamiento_GSE239520`; S9 =
`S5_sensibilidad_almacenamiento`; S10 = `E1_edad_resumen` and `E1_interaccion_resumen`; S11 =
`TABLA4_locus_tres_cohortes` (complete statistics).

## Environment

R 4.3.3 with minfi 1.48.0, wateRmelon 2.8.0, limma 3.58.1, EpiDISH 2.18.0, DMRcate 2.16.1,
impute 1.76.0, statmod 1.5.2, data.table 1.18.4, IlluminaHumanMethylationEPICanno.ilm10b4.hg19 0.6.0,
IlluminaHumanMethylationEPICmanifest 0.3.0, Gviz and TxDb.Hsapiens.UCSC.hg19.knownGene (figures), and
EpiSmokEr 0.1.0, which is not on Bioconductor and can be installed with
`remotes::install_github("sailalithabollepalli/EpiSmokEr")` (01d attempts this if it is missing).
Full `sessionInfo()` output is in `outputs/sessionInfo_*.txt`.
